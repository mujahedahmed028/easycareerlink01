# Easy Career Link Website Replica (HTML/CSS/JS)

This archive contains the complete standalone static website replica of Easy Career Link (https://easycareerlink.com/).

## Directory Contents
- `index.html`: Main HTML5 page with SEO meta tags, OpenGraph, Twitter Cards, Schema.org JSON-LD, and semantic sections.
- `styles.css`: Complete responsive CSS stylesheet with Fraunces serif and Plus Jakarta Sans font imports, custom design tokens, and media queries.
- `script.js`: Vanilla JavaScript handling the consultation modal, real-time profile readiness calculator, strategy tabs, and quote carousel.
- `images/`:
  - `logo.png`: Official Easy Career Link logo.
  - `hero-workspace.png`: Workspace illustration with candidate materials.
  - `career-path-infographic.png`: The "Right Direction, Better Results" roadmap diagram.

## How to Run Locally
Simply double-click `index.html` to open it in any web browser (Chrome, Safari, Firefox, Edge). No Node.js, build step, or web server required!

## Deploying to Production
You can upload these files directly to any static web hosting platform:
- GitHub Pages
- Netlify (drag-and-drop the unzipped folder)
- Vercel
- Cloudflare Pages
- AWS S3 / CloudFront
- Traditional Apache / Nginx web servers
